# Есть дефект или нет

Простое решение задания репетиции HackAlem AI по компьютерному зрению. Скрипт
принимает путь к изображению и печатает `OK` или `DEFECT`.

## Как работает

Решение не использует ML-модель. Оно считает ярко-красные пиксели, в которых
красный канал заметно сильнее зелёного и синего. Если доля таких пикселей не
меньше `0.2%`, изображение считается дефектным. Разница между каналами нужна,
чтобы коричневые крыша и дверь не воспринимались как дефект.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Активация окружения в PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установка зависимости:

```bash
python -m pip install -r requirements.txt
```

Проверка изображений:

```bash
python detect.py ok.jpg
# OK

python detect.py defect.jpg
# DEFECT
```

В репозитории находятся два тестовых изображения: обычный дом `ok.jpg` и тот
же дом с красными отметками `defect.jpg`. На первом скрипт выдаёт `OK`, на
втором — `DEFECT`.
